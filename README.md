# Планировщик ликвидности и денежных потоков

Автоматизированная система внутрибанковского операционного планирования и управления лимитами ликвидности.

## Описание проекта

Планировщик ликвидности и денежных потоков — это веб-дашборд для казначейства, риск-менеджмента и руководства банка. Система помогает контролировать текущую и прогнозную ликвидность, видеть кассовые разрывы, управлять заявками подразделений, отслеживать лимиты и фиксировать действия пользователей в журнале аудита.

## Актуальность

В банках планирование ликвидности часто выполняется вручную: через Excel, бумажные заявки и переписку между подразделениями. Такой процесс повышает риск ошибок, задержек согласования, кассовых разрывов и неэффективного использования свободных денежных средств.

Проект решает эту проблему за счет единого интерфейса, где денежные потоки, лимиты, заявки, роли и прогнозы сведены в одну операционную картину.

## Цель

Разработать прототип автоматизированной системы для:

- расчета текущей и прогнозной ликвидности;
- контроля лимитов по валютам;
- обработки заявок подразделений;
- согласования операций;
- выявления риска кассового разрыва;
- ведения журнала аудита;
- подготовки управленческой отчетности.

## Основной функционал

- Дашборд ликвидности банка.
- Прогноз денежных потоков на 7 дней.
- Сценарии прогноза: базовый, стрессовый, оптимистичный.
- Фильтр валют: KGS, USD, EUR, CNY.
- Создание заявок подразделений.
- Согласование и отклонение заявок.
- Ролевая модель доступа.
- Настройка минимального лимита ликвидности.
- Центр предупреждений по рискам и лимитам.
- Операционный контрольный список для казначейства.
- Блок презентационной готовности проекта.
- Краткая карта эффекта для банка: скорость расчета, риск, свободные ресурсы, аудит.
- Отдельный раздел для защиты проекта с тезисами и ответами на вопросы.
- Журнал аудита действий.
- Поиск и фильтрация операций.
- Экспорт операций в табличном формате.
- Отдельный раздел заявок подразделений.
- Отдельный раздел отчетности.
- Отдельный раздел настроек ролей, лимитов и будущих интеграций.
- Список доработок до промышленной банковской версии.

## Роли пользователей

| Роль | Возможности |
|---|---|
| Казначей | Создание заявок, согласование операций, контроль ликвидности |
| Риск-менеджер | Настройка лимитов, контроль нарушений |
| Руководитель | Просмотр сводки, утверждение критических решений |
| Аудитор | Просмотр данных и журнала действий |

## Архитектура будущей версии

Промышленная версия системы должна включать:

- пользовательский интерфейс для сотрудников банка;
- серверный интерфейс программирования приложения для расчетов, заявок, лимитов и аудита;
- базу данных для хранения операций и истории действий;
- интеграционный слой с АБС, кредитным, депозитным и валютным модулями;
- сервис уведомлений;
- модуль отчетности;
- модуль безопасности и ролевого доступа.

## Что реализовано в текущем прототипе

Текущая версия является интерактивным прототипом пользовательского интерфейса. Данные сохраняются в локальном хранилище браузера. Это позволяет показать основные пользовательские сценарии без подключения серверной базы данных.

Дополнительно добавлен презентационный слой: паспорт проекта, готовность модулей, ожидаемый эффект для банка, сценарий демонстрации и ответы на возможные вопросы комиссии.

## Что нужно доработать для промышленной версии

## Сценарий презентации

1. Объяснить проблему ручного планирования ликвидности.
2. Показать главный дашборд и прогноз.
3. Переключить сценарии прогноза.
4. Создать новую заявку.
5. Показать изменение прогноза после заявки.
6. Согласовать или отклонить заявку.
7. Показать журнал аудита.
8. Переключить роли пользователей.
9. Показать настройку лимитов от роли риск-менеджера.
10. Открыть разделы заявок, отчетов и настроек.
11. Открыть вкладку с доработками до промышленной версии.
